# Protocolos-emerg-ncia

Projeto Final - Protocolos de Comunicação e Tendências Futuras

## Conteúdo
- **5G:** latência 1ms, network slicing
- **QUIC:** RFC 9000, UDP 443 + TLS 1.3, mais rápido que TCP
- **IoT:** MQTT 8883, CoAP 5684, LoRaWAN
- **Padronização:** IETF (RFCs), IEEE (802.11 Wi-Fi), ITU (5G)

## Caso Prático - Comparativo
- **E-mail:** 587 (envio seguro) + 993 (leitura IMAP segura). 25 é relay, 110 é obsoleto sem TLS
- **Vídeo:** RTMP para enviar + WebRTC/QUIC para distribuir live
- **IoT:** MQTT para sensores
